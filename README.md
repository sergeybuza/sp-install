# Установка Смарт Платформы

Проект для подготовки и проверки установки Смарт Платформы на промышленные ПК под управлением Ubuntu Linux. Смарт Платформа — глубокий форк ThingsBoard (TB); поставка предполагается в виде Docker-образов.

Основание для описания проекта — вводные владельца. Руководство пользователя и черновик инструкции ожидаются; их содержание ещё не проверено. Исходные материалы могут содержать ошибки.

## Структура

| Путь | Назначение |
| --- | --- |
| `AGENTS.md` | Правила работы агента и границы доступа |
| `docs/source/` | Руководства, черновики и другие исходные материалы поставщика |
| `docs/review/` | Замечания к исходным материалам, вопросы и результаты проверок |
| `docs/installation/` | Проверенная инструкция установки, обновления, восстановления и диагностики |
| `inventory/` | Характеристики целевых ПК, версии Ubuntu и состав поставки |
| `deploy/compose/` | Файлы Docker Compose, когда будет подтверждён состав сервисов |
| `deploy/config/` | Шаблоны конфигурации без паролей и ключей |
| `images/` | Локальные архивы Docker-образов, если они поставляются файлами; содержимое исключено из Git |
| `scripts/` | Скрипты подготовки, установки и проверок после уточнения требований |

## Порядок работы

1. Сохранить полученные документы в `docs/source/`, сохраняя оригиналы и сведения об их версии и происхождении.
2. Зафиксировать в `inventory/` характеристики ПК и поставки: архитектуру процессора, ресурсы, версию Ubuntu, образы и их теги или дайджесты.
3. Проверить черновик инструкции. Вопросы и ошибки записать в `docs/review/` со ссылками на документ, раздел или страницу.
4. По подтверждённым требованиям подготовить конфигурацию в `deploy/` и необходимые скрипты в `scripts/`.
5. Проверить установку в согласованном окружении и записать точные версии, выполненные команды и результаты в `docs/installation/`.

До получения поставки неизвестны версии Ubuntu и Docker, архитектура образов, состав сервисов, порты, тома и требования к ресурсам. Готовой конфигурации развёртывания и установочных скриптов пока нет.

## Работа с материалами

- Не переносить требования и команды ThingsBoard на Смарт Платформу без проверки.
- Отделять утверждения из руководства от результатов фактического запуска.
- Не хранить в Git пароли, токены, закрытые ключи, рабочие `.env`, данные платформы, резервные копии и архивы образов. Публичные шаблоны окружения называть `.env.example`.
- Перед добавлением материалов в Git проверять их на секреты и персональные данные. `.gitignore` не заменяет такую проверку.
- Подключение внешних ресурсов и доступ за пределы каталога проекта требуют разрешения по правилам `AGENTS.md`.
