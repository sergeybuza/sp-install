# Установка и нагрузочное тестирование Смарт Платформы

Проект для подготовки и проверки установки Смарт Платформы на промышленные ПК с Ubuntu Linux, подключённые по локальной сети, а также проверки работы платформы под нагрузкой. По вводным владельца, Смарт Платформа — глубокий форк ThingsBoard (TB), поставляемый в виде Docker-образов.

На входе — Docker-образы и черновая документация поставщика. Рабочий компьютер с этим проектом и целевой промышленный ПК — разные машины.

## С чего начать

- [AGENTS.md](AGENTS.md) — правила работы: доступ, внесение изменений через PR, секреты и обязательная проверка Gitleaks.
- [Стенды](inventory/hosts/README.md) — выбор узла и ссылки на карточки с реквизитами, окружением и последним зафиксированным состоянием.
- [Подготовка Docker на Ubuntu 26.04](docs/installation/ubuntu-26-docker.md) и [установка Смарт Платформы 2.0.0](docs/installation/smart-platform-2.0.0.md) — процедуры и границы выполненных проверок.
- [Инвентарь поставки 2.0.0](inventory/releases/smart-platform-2.0.0.md) — состав, идентификаторы образов и контрольные суммы.
- [Локальный MCP 1.0.0](docs/installation/sp-mcp-local.md) — запуск на Mac, проверка чтения платформы и подключение Codex/Claude Code.
- [Замечания к исходным документам](docs/review/2026-11-12-installation-documents.md) — выявленные ошибки и основания для исправлений.

Адреса и состояние стендов обновляются в их карточках. Результаты конкретных запусков связаны с карточками и документами в `docs/review/`.

## Проверка работы под нагрузкой

Для нагрузочных сценариев предусмотрены два инструмента отдельной локальной поставки:

- `highload` эмулирует поток данных: PubMQTT публикует сигналы по сценарию из Excel-файла, а Agent передаёт их через MQTT в Смарт Платформу. Путь к инструкции — `input/highload/DEPLOY.md`.
- `mcp` предоставляет MCP-сервер Смарт Платформы для подключения ИИ-клиента. Его планируется использовать для создания разных дашбордов и проверки их работы на фоне поступающего потока данных. Путь к инструкции — `input/mcp/DEPLOY_MCP.md`.

2026-11-14 выполнен [пробный запуск highload на Mac](docs/installation/highload-mac.md)
с отправкой на установочный стенд: 10 устройств, 100 сигналов с периодом
1000 мс. Сохранение и обновление телеметрии подтверждены через API;
[результаты и границы проверки](docs/review/2026-11-14-highload-mac.md).

Для быстрого управления используйте `./highload set 20 100`, `./highload stop`,
`./highload start`, `./highload status` и `./highload check` на Mac.
Числа — устройства и сигналы на каждом; необязательный `--period-ms`
задаёт период. [Инструкция инструмента](docs/installation/highload-mac.md#быстрое-управление-нагрузкой),
[результаты приёмки](docs/review/2026-11-14-highload-control.md).

Если этих материалов нет в рабочей копии, их нужно получить перед использованием инструментов.

Создание дашбордов через MCP требует отдельной проверки: в прежнем разборе `DEPLOY_MCP.md` отмечено противоречие между описанием сервера как доступного только для чтения и упоминанием режима записи. Это целевой сценарий проекта, а не подтверждённая возможность поставки.
