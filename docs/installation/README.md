# Инструкция установки

[ПРОВЕРЕНО] Для стенда `192.168.10.107` восстановлена [подготовка Docker на Ubuntu 26.04](ubuntu-26-docker.md): команды из журналов sudo и APT сопоставлены с установленными пакетами и состоянием службы. Проверка выполнена 2026-11-12; пакеты повторно не устанавливались.

Полной проверенной инструкции установки Смарт Платформы пока нет: [четыре образа 2.0.0](../../inventory/releases/smart-platform-2.0.0.md) получены, экспортированы и загружены на стенд, но контейнеры не запускались. Зависимости и запуск ещё требуют проверки. См. [замечания к исходным документам](../review/2026-11-12-installation-documents.md). Проверка Docker и загрузка образов не подтверждают работоспособность платформы, её TLS или веб-интерфейса.

По мере проверки документируйте:

1. Требования к оборудованию и поддерживаемые версии Ubuntu, Docker и Compose.
2. Доступ к ПК по локальной сети и подготовку окружения.
3. Передачу поставки, загрузку образов, конфигурацию сервисов и первый запуск.
4. Проверку работоспособности с конкретными ожидаемыми результатами.
5. Остановку, обновление, резервное копирование и восстановление.
6. Диагностику известных ошибок.

Для каждой команды указывайте место выполнения: рабочий компьютер или целевой промышленный ПК. Доступ к проверенному стенду — SSH TCP 22, engineer с sudo; значения секретов передаются через окружение, не через файлы.

Для каждой проверенной процедуры указывайте дату, целевой ПК, окружение, версии и фактический результат. Подробные результаты запусков храните локально в `reports/`. Разрушающие команды должны сопровождаться описанием затрагиваемых данных.
