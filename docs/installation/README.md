# Инструкция установки

Здесь будет проверенная инструкция для целевого промышленного ПК с Ubuntu Linux. Пока установка не выполнялась; команды и требования к окружению не подтверждены.

По мере проверки документируйте:

1. Требования к оборудованию и поддерживаемые версии Ubuntu, Docker и Compose.
2. Подготовку ПК и получение поставки.
3. Загрузку образов, конфигурацию сервисов и первый запуск.
4. Проверку работоспособности с конкретными ожидаемыми результатами.
5. Остановку, обновление, резервное копирование и восстановление.
6. Диагностику известных ошибок.

Для каждой проверенной процедуры указывайте дату, окружение, версии и фактический результат. Разрушающие команды должны сопровождаться описанием затрагиваемых данных.
