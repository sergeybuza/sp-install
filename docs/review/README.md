# Проверка документации

Здесь фиксируются замечания к материалам из `input/docs/` и результаты их проверки.

Для каждого замечания укажите:

- исходный файл, версию при наличии, раздел или страницу;
- спорное утверждение или команду;
- проблему и предлагаемое исправление;
- основание: документ, вывод команды или результат запуска;
- состояние: требует проверки, подтверждено, исправлено или отклонено с причиной.

Утверждение из документа помечайте как подтверждённое только в пределах выполненной проверки. Для запуска указывайте окружение и точные версии.
