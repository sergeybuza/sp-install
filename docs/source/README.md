# Исходные материалы

Сюда помещаются полученные руководства, черновики инструкций и сопроводительные документы. Пока материалы не предоставлены.

Сохраняйте оригинальные файлы без правок. Для каждой поставки фиксируйте дату получения, источник и версию документа, если она известна. Не указывайте вымышленные версии.

Ошибки и вопросы записывайте в `docs/review/`. Само наличие команды в руководстве не означает, что она проверена.
