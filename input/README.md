# Входная поставка

- `images/` — полученные файлы Docker-образов. Образы исключены из Git.
- `docs/` — исходные руководства, черновики инструкций и сопроводительные документы.
- `ca.crt` — предоставленный владельцем публичный Andromeda Root CA для Java truststore; оригинал не изменяется и остаётся локальным.

Для нескольких поставок используйте отдельные подпапки с согласованными идентификаторами в обоих каталогах. Оригиналы сохраняйте без правок. Состав каждой поставки описывайте в `inventory/releases/`; замечания к документации — в `docs/review/`.
