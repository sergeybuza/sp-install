# Документация поставщика

Сюда помещаются полученные руководства, черновики инструкций и сопроводительные документы.

2026-11-12 владелец предоставил локальные оригиналы:

- `Инструкция по развороту СП rev.01.docx` — короткая инструкция; rev.01 указан в имени файла, версия поставки не определена.
- `РП. Смарт Платформа.pdf` — руководство пользователя, 500 страниц; версия поставки не установлена.

Оригиналы не изменены и в PR с результатами проверки не включаются. Замечания находятся в [docs/review](../../docs/review/2026-11-12-installation-documents.md). Служебные файлы открытого редактора не являются материалами поставки.

Сохраняйте оригинальные файлы без правок. Для каждой поставки фиксируйте дату получения, источник и версию документа, если она известна. Не указывайте вымышленные версии.

Ошибки и вопросы записывайте в `docs/review/`. Само наличие команды в руководстве не означает, что она проверена.
