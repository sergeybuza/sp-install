# Архивы Docker-образов

Если поставщик передаёт образы файлами, храните их локально в этой папке. Кроме этого описания, содержимое папки исключено из Git.

Состав поставки, версии, архитектуры, дайджесты образов и контрольные суммы архивов фиксируйте в `inventory/releases/` по полученным данным.

[ПРОВЕРЕНО] 2026-11-12 из Docker рабочего компьютера экспортирован `sp-images-2.0.0.tar` с четырьмя образами поставки 2.0.0, `linux/amd64`. Размер и SHA-256 записаны в [инвентаре](../../inventory/releases/smart-platform-2.0.0.md); после передачи на стенд контрольная сумма совпала, `docker load` завершился успешно. Архив исключён из Git. Экспорт образов не включает пользовательские данные и тома контейнеров.
