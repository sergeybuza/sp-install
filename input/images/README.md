# Архивы Docker-образов

Если поставщик передаёт образы файлами, храните их локально в этой папке. Кроме этого описания, содержимое папки исключено из Git.

Состав поставки, версии, архитектуры, дайджесты образов и контрольные суммы архивов фиксируйте в `inventory/releases/` по полученным данным. Архивы пока не предоставлены.
