# Окружение и состав поставки

[ПРОВЕРЕНО] На [установочном стенде](hosts/stand/README.md) проверены окружение и монолитное развёртывание [Смарт Платформы 2.0.0](releases/smart-platform-2.0.0.md). Сведения относятся к проверке от 2026-11-12; они не подтверждают совместимость других ПК или релизов.

## Целевые ПК — `hosts/`

Для каждого ПК создайте отдельное описание под согласованным именем и зафиксируйте:

- адрес или имя ПК в локальной сети, способ удалённого доступа и имя учётной записи (без её пароля);
- модель ПК, архитектуру CPU, объём RAM и доступное место на диске;
- точную версию Ubuntu;
- версии Docker Engine и Docker Compose;
- пути размещения платформы и её данных на целевом ПК;
- установленную поставку и фактическое состояние установки.

## Поставки — `releases/`

Для каждой поставки создайте отдельное описание и зафиксируйте:

- источник, дату получения и идентификатор поставки;
- список образов, их архитектуры, теги и дайджесты при наличии;
- имена полученных файлов в `input/images/` и их контрольные суммы;
- связанные документы и их версии из `input/docs/`;
- состав сервисов, внешние зависимости, порты и требования к сети;
- тома, пути хранения данных, требования к резервному копированию;
- настройки перезапуска и запуска после включения ПК.

Не храните здесь пароли, токены и закрытые ключи. Для каждого значения указывайте источник или способ проверки; неизвестные значения оставляйте явно неизвестными.
