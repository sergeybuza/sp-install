# Окружение и состав поставки

Инвентарь разделён на описания стендов и составы поставок. Результаты проверки одного ПК или релиза не подтверждают совместимость остальных.

## Целевые ПК — `hosts/`

[Справочник стендов](hosts/README.md) содержит список узлов, ссылки на их карточки и порядок обновления сведений при изменении окружения.

## Поставки — `releases/`

Для каждой поставки создайте отдельное описание и зафиксируйте:

- источник, дату получения и идентификатор поставки;
- список образов, их архитектуры, теги и дайджесты при наличии;
- имена полученных файлов в `input/images/` и их контрольные суммы;
- связанные документы и их версии из `input/docs/`;
- состав сервисов, внешние зависимости, порты и требования к сети;
- тома, пути хранения данных, требования к резервному копированию;
- настройки перезапуска и запуска после включения ПК.

Не храните здесь пароли, токены и закрытые ключи. Для каждого значения указывайте источник или способ проверки; неизвестные значения оставляйте явно неизвестными.
