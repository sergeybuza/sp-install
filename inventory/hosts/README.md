# Стенды

Здесь ведётся список стендов проекта. Реквизиты подключения, окружение и последнее зафиксированное состояние находятся в отдельной карточке каждого узла.

| Идентификатор | Назначение | Описание |
| --- | --- | --- |
| `stand` | Установка и проверка монолитной Смарт Платформы | [Карточка стенда](stand/README.md) |

## Содержание карточки

Для каждого ПК фиксируйте:

- адрес или имя в локальной сети, способ доступа, порт и имя учётной записи;
- имена переменных окружения для подключения без значений секретов;
- модель ПК, архитектуру CPU, объём RAM и доступное место на диске;
- точные версии Ubuntu, Docker Engine и Docker Compose;
- пути размещения платформы и её данных;
- установленную поставку и последнее зафиксированное состояние;
- дату и часовой пояс проверки, источник сведений, выполненные и невыполненные проверки.

Неизвестные значения указывайте как неизвестные. Сведения владельца и результаты команд описывайте с указанием источника. Дата записи означает время наблюдения, а не гарантию доступности стенда сейчас.

## Изменение состава и окружения

1. Для нового узла создайте каталог под согласованным идентификатором и карточку `<идентификатор>/README.md`, затем добавьте ссылку в таблицу выше.
2. При изменении адреса, оборудования, ОС, поставки или состояния обновляйте карточку узла. Корневые `README.md` и `AGENTS.md` ссылаются на этот справочник и не содержат копий реквизитов.
3. Предыдущее состояние сохраняйте в `history.md` рядом с карточкой либо в датированном документе `docs/review/`, со ссылкой из карточки. Подробные отчёты отдельных запусков остаются локально в `reports/`.
4. При выводе стенда из работы отметьте это в карточке и справочнике. При замене физического ПК создайте новую карточку, сохранив историю прежнего узла.
