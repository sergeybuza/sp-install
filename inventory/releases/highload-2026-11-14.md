## Образы

в архиве, затем через `docker image inspect` после `docker load`.
Mosquitto уже имелся в Docker Mac; его скачивание не выполнялось.

## Сценарий и зависимости

Первый лист `config/test_sp_local.xlsx`: 100 строк сигналов, 10 устройств,
период 1000 мс, лимит сообщений `J=0` во всех строках. Типы: 20 `random`,
20 `saw`, 20 `triangle`, 40 `sin`. Колонки после K не используются.

Фактически использованы три сервиса: PubMQTT → локальный Mosquitto → Agent
→ внешний Mosquitto платформы на 1884. Внешние Docker-сети, опубликованные
порты Mac и постоянные тома не требуются. SQLite Agent находится в tmpfs;
постоянного буфера и процедуры его резервного копирования для этого
пробного запуска нет. Логи Agent отключены; остальные логи ограничены
двумя файлами по 5 MiB на контейнер. Конфиги и сценарий монтируются read-only.

Минимальные ресурсы поставщик не указал. Наблюдение при стандартном потоке:
три контейнера суммарно около 50 MiB RAM; это не гарантия потребления при
другом сценарии. Политика `unless-stopped` задана, восстановление после
перезагрузки Mac не проверялось.
