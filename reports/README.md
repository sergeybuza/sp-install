# Результаты запусков

Храните здесь локальные результаты установки и диагностики: `reports/<имя-ПК>/<дата-и-время-запуска>/`. Кроме этого описания, содержимое папки исключено из Git.

Фиксируйте целевой ПК, поставку, окружение, выполненные команды, их коды завершения и результаты проверок. Секреты в выводе команд скрывайте.

Подтверждённые выводы и воспроизводимые процедуры переносите в `docs/review/` и `docs/installation/` после проверки на секреты и рабочие данные.
