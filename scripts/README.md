# Скрипты

Скрипты подготовки, установки и проверки добавляются после подтверждения требований поставки.

[ПРОВЕРЕНО ПО ПОСТАВКЕ] [checks/platform-http.py](checks/platform-http.py) использует фактические endpoints авторизации 2.0.0. Скрипт предназначен для рабочего компьютера или стенда с Python 3: проверяет сертификат HTTPS, HTML и локальные JS/CSS ресурсы, вход системного администратора и получение пользователя через API. Пароль берётся только из `SP_ADMIN_PASSWORD`, логин — из `SP_ADMIN_USERNAME` (по умолчанию системный логин поставки). Секреты и ответы API не печатаются, внешние перенаправления запрещены. Проверен синтаксис; сама платформа ещё не запущена, поэтому сетевые проверки не выполнялись.

После развёртывания запускать с `--url https://192.168.10.107 --ca-cert /путь/к/публичному/сертификату`, предварительно передав пароль в окружение. Не передавать пароль аргументами CLI и не сохранять в `.env`.

- `local/` — выполняются на рабочем компьютере: подготовка, передача поставки по локальной сети, управление установкой.
- `remote/` — выполняются на целевом промышленном ПК: подготовка Ubuntu и развёртывание платформы.
- `checks/` — проверяют готовность окружения и работоспособность платформы; каждый скрипт должен явно указывать место выполнения.

Указывайте назначение, поддерживаемое окружение, необходимые права и затрагиваемые пути. Проверяйте входные параметры; повторный запуск должен быть предсказуемым. Изменения данных и системных настроек описывайте до команды запуска.
